# 星の翼 スターパートナー X投稿申請アシスト（Chrome拡張機能）

自分のX（Twitter）に投稿したイラスト・同人小説のポストを収集し、
「スターパートナー」Twitter絵画投稿/同人小説 申請フォーム（wj.qq.com）へ
転記・送信する作業を半自動化するChrome拡張機能です。

YouTube版（[starward_starpartner_assistapp](https://github.com/mizuha-kusunoki-v/starward_starpartner_assistapp)）と
同じ考え方・構成で作っています。

## YouTube版との違い

| | YouTube版 | X版（本拡張） |
| --- | --- | --- |
| 投稿の取得元 | YouTube Data API（APIキー） | ログイン済みブラウザで開いたXの検索結果ページ（APIキー不要） |
| 絞り込み | 動画タイトルのキーワード | 除外語 → 対象キーワード → 作品の手がかり（下記） |
| 自動推測 | ビデオタイプ・投稿内容カテゴリ | キャラクター欄（本文のキーワード対応表） |
| フォーム項目 | 8項目 | Twitter名 / Discord ID / ツイートリンク / 投稿日 / キャラクター |

X公式APIは投稿の読み取りが有料のため、APIは使わず、ユーザー自身のブラウザで
`from:自分 since:… until:…` の検索結果を開き、自動スクロールしながら画面上の投稿を読み取ります。

## セットアップ

```bash
npm install
npm run build
```

1. `chrome://extensions` を開き「デベロッパーモード」をON
2. 「パッケージ化されていない拡張機能を読み込む」で **`dist`** フォルダを選択
3. ツールバーの拡張機能アイコンをピン留め（クリックでダッシュボードが開きます）

ソース変更時は `npm run build`（または `npm run watch`）後、拡張機能カードの再読み込みボタンを押し、
開いているダッシュボード/設定タブもリロードしてください。

## 初期設定

拡張機能アイコンを右クリック→「オプション」から:

- 申請フォームURL（運営から案内されたもの。ソースコードには含めていません）
- Twitter名（フォームに転記する登録用ニックネーム）
- DiscordのID
- 自分のXユーザー名（@以降）
- 対象投稿の判定条件（下記）
- キャラクター欄の自動推測ルール（キャラクター名 ⇔ 本文キーワード）と、マッチしない場合の既定値

## 対象投稿の判定

小説は画像なしで投稿されることが多いため、「画像付きかどうか」だけでは判定できません。
取得した対象月の投稿を、次の順で判定します（`src/lib/classify.ts` の `evaluateTweet`）。

1. **除外キーワード**を1つでも含む → 対象外（ガチャ・配信告知など）
2. **対象キーワード**（ゲーム名・運営指定タグ・表記ゆれ）をどれも含まない → 対象外
3. **作品の手がかり**が1つもない → 対象外（設定でOFF可）
   - 画像/動画が付いている
   - 小説を示す語（小説, SS, 夢小説 …）を含む
   - 小説・作品投稿サイト（pixiv, privatter, ふせったー, ポイピク, ハーメルン, カクヨム …）へのリンク
   - 長文（既定140文字以上、または「さらに表示」付きのX Premium長文ポスト）

キーワード・小説語は本文に加えてリンクカードの表示文言（例: pixivの「〇〇の小説」）も照合します。
英数字だけの語（SS など）は単語単位で照合するため、class や boss には一致しません。
スレッド形式の小説は、2件目以降（自分へのリプライ）を検索時点で除外しているため、1件目だけが候補になります。

どれだけ条件を足しても判定漏れはゼロにはできないため、**対象外になった投稿も捨てずに保持**しています。
ダッシュボードの「対象外の投稿も表示」をONにすると理由付きで表示され、手動でチェックして送信できます。
一覧の「判定」列に、対象と判定した根拠（キーワード / 画像 / 小説リンク など）が出ます。

## 使い方

1. 事前に Chrome で x.com にログインしておく
2. ダッシュボードで対象年月を選び「Xから投稿を取得」
3. Xの検索結果タブが開いて自動スクロールします。終わるまでそのタブを操作せず待つ
4. 一覧に対象と判定された投稿が表示されます。判定漏れが気になる場合は「対象外の投稿も表示」で確認します。
   キャラクター欄は自動推測され、手で修正できます
   （空欄のままの行があると送信ボタンは押せません）
5. 送信済みの投稿はグレーアウトされ、選択対象から外れます
6. 送信したい投稿にチェックを入れ「選択した投稿を一括送信」
7. 1件ずつフォームのタブを開いて自動入力・送信します。
   エラー時は自動送信を止め、該当タブを開いたままにするので手動で確認・完了してください

## 注意事項・既知の制約

- フォーム送信は**完全無人の連続送信ではなく**、一覧で確認・選択した上で実行する半自動方式です。
- `src/content/formFiller.ts` は 2026年9月時点の wj.qq.com のDOM構造に合わせています（設問見出しの完全一致で項目を特定）。
- `src/content/xCollector.ts` は Xの `data-testid` 属性に依存しています。X側の変更で取得できなくなった場合はセレクタを見直してください。
- Xの検索は時期や件数によって結果が欠けることがあります。取得件数が想定より少ない場合は、
  Xの検索結果を目視で確認してください。
- 投稿日は日本時間（JST）の暦日で扱います。
- 本番フォームへ送信する前に、まず1件だけで試し、wj.qq.com側で正しく送信されたことを確認してください。
