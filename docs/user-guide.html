使い方ガイド

最終更新日: 2026年9月30日

「星の翼 スターパートナー X投稿申請アシスト」は、X（旧Twitter）に投稿したイラストや小説を 「スターパートナー」プログラムの申請フォーム（Twitter絵画投稿/同人小説）へ登録する作業を 半自動化するChrome拡張機能です。

これまで1件ずつ「投稿のリンクをコピー → フォームを開く → 名前やIDを入力 → 日付を選ぶ → 送信」と 繰り返していた作業を、一覧で確認してボタンを押すだけにできます。

1. インストール

  1. Chromeウェブストアの「星の翼 スターパートナー X投稿申請アシスト」のページを開く
  2. 「Chromeに追加」をクリック
  3. 確認ダイアログが出たら「拡張機能を追加」をクリック

インストール後、Chromeのツールバー右上の パズルピースのアイコン（拡張機能） から 本拡張機能を見つけてピン留めしておくと、次回から使いやすくなります。

パソコン版のGoogle Chromeで使います。スマートフォンのChromeでは使えません。

2. 初期設定

最初に一度だけ、設定画面で以下を入力します。 拡張機能のアイコンを右クリック →「オプション」、または拡張機能アイコンをクリックして 開くダッシュボード画面の「設定を開く」から設定画面に入れます。 入力が終わったら、画面いちばん下の「保存」を押してください。

2-1. 申請フォームURL（最重要）

このツールには申請フォームのURLは含まれていません。運営から個別に案内された 「Twitter絵画投稿/同人小説」用フォームのURLを、ご自身で入力してください。 動画用（YouTube）のフォームとは別のフォームなので注意してください。

2-2. Twitter名・Discord ID

  • Twitter名: 申請フォームにいつも記入している登録用ニックネームを入力してください。 Xの表示名を変えていても、これまで申請に使ってきた名前をそのまま使います
  • DiscordのID: Discordの数字のIDではなく、ご自身で設定したユーザー名を入力してください

2-3. 自分のXユーザー名

Xのプロフィールに表示されている @ から始まる名前の、@ より後ろの部分を入力します。 （例: @starward_fan なら starward_fan。@ を付けたままやプロフィールのURLを貼り付けても自動で直します）

YouTube版と違い、APIキーなどの面倒な準備は不要です。 そのかわり、使うときに ChromeでXにログインしている必要があります。

2-4. 対象投稿の判定

Xから取得した投稿のうち、どれを申請対象として一覧に出すかを決める条件です。 最初はそのままでも使えますが、次の2つだけは確認してください。

  • ① 対象キーワード: 申請する投稿に必ず入れているゲーム名やハッシュタグを入れます。 複数あるときはカンマ（,）で区切ります。
    例: #星の翼, 星の翼, Starward
    小説に別のタグ（例: #星の翼SS）を付けている場合は、それも入れておくと確実です
  • ② 除外キーワード: この言葉が入っている投稿は対象外にします。 ゲームの話題でも作品ではない投稿（例: ガチャ, 配信告知, 相互）を入れます

その下の「小説を示す語」「小説・作品投稿サイトのドメイン」「長文とみなす文字数」は、 小説の投稿を見分けるための設定です。詳しくは4. 投稿の選ばれ方をご覧ください。

2-5. キャラクター欄の自動推測ルール

申請フォームの「キャラクター」欄を、投稿の本文から自動で埋めるための対応表です。

キャラクター（フォームに入る文字）キーワード（本文にこれがあれば）
「嘆きの魔竜」ライン魔竜, 嘆きの魔竜

上の行から順に調べて、最初に当てはまったキャラクターが入ります。 どれにも当てはまらないときは「マッチしなかった場合の既定値」が入り、それも空欄ならダッシュボードで手入力します。 よく描く・書くキャラクターを登録しておくと手間が減ります（一覧画面でいつでも手直しできます）。

3. 使い方

  1. ChromeでXにログインしていることを確認する
  2. 拡張機能アイコンをクリックしてダッシュボードを開く
  3. 「対象年月」を選び、「Xから投稿を取得」をクリック
  4. Xの検索結果のタブが自動で開き、画面が自動でスクロールしていきます。 終わるまでそのタブには触らずお待ちください（投稿数によって数十秒〜数分）。 終わるとタブは自動で閉じ、ダッシュボードに戻ります
  5. 申請対象と判定された投稿が一覧に出ます。本文・投稿日・「判定」欄（なぜ対象になったか）・キャラクター欄を確認し、 必要ならキャラクター欄を直します。キャラクター欄が赤くなっている投稿は入力が必要です
  6. 送信したい投稿にチェックを入れる（送信済みの投稿は自動的にグレーになり、対象から外れます）
  7. 「選択した投稿を一括送信」をクリック
  8. 拡張機能が1件ずつ申請フォームのタブを自動で開き、入力・送信します。完了すると一覧の「状態」欄が「送信完了」になります
全自動で無人送信され続けるわけではありません。 何らかの理由で入力・送信に失敗した場合は、そこで自動処理が止まり、該当のタブが開いたままになります。 その場合はタブの内容を確認して手動で送信を完了させてから、必要であれば残りの投稿を選び直してもう一度 「一括送信」を実行してください。
はじめて使うときは、まず1件だけチェックして送信し、正しく申請できたことを確認してから まとめて送信することをおすすめします。

4. 投稿の選ばれ方（判定のしくみ）

その月に自分が投稿したポスト（リプライ・リポストを除く）をすべて読み取り、次の順番で申請対象かどうかを判定します。

  1. 除外キーワードが入っている → 対象外
  2. 対象キーワードがどれも入っていない → 対象外
  3. 作品らしい手がかりが1つもない → 対象外。手がかりは次の4つです
    • 画像/動画 画像や動画が付いている（イラスト・漫画・小説の画像など）
    • 小説語 「小説」「SS」「夢小説」「短編」などの言葉が入っている
    • 小説リンク pixiv・privatter・ふせったー・ポイピク・ハーメルン・カクヨムなどへのリンクがある
    • 長文 本文が長い（初期設定では140文字以上、またはX Premiumの長文ポスト）

小説は画像を付けずに投稿されることが多いため、画像以外の手がかりでも見分けられるようにしています。 ダッシュボードの「判定」欄には、どの手がかりで対象になったかが表示されます。

対象外になった投稿を拾うには

どんなに条件を工夫しても、判定から漏れてしまう投稿はあります（例: タグも画像も付けていない短い小説）。 そのため、対象外になった投稿も捨てずに残しています。

  1. ダッシュボードの「対象外の投稿も表示」にチェックを入れる
  2. 対象外の投稿が薄い色で、理由（例: 「対象外: 作品の手がかりなし」）と一緒に表示されます
  3. 申請したい投稿があれば、手動でチェックを入れて送信できます

同じような漏れが何度も起きる場合は、その投稿に入っている言葉を設定の「対象キーワード」や「小説を示す語」に 追加すると、次からは自動で対象になります。逆に、関係ない投稿が対象に混ざる場合は「除外キーワード」に追加してください。

5. よくある質問・困ったときは

Q.「Xにログインしていません」と表示される

ChromeでXにログインしていない状態です。開いたままになっているXのタブでログインしてから、 ダッシュボードでもう一度「Xから投稿を取得」を押してください。

Q. 投稿が1件も取得できない・対象が0件になる

  • 設定画面の「自分のXユーザー名」が正しいか確認してください
  • 「対象年月」が正しいか確認してください
  • 「対象外の投稿も表示」にチェックを入れて、投稿が対象外として判定されていないか確認してください。 理由が「対象キーワードなし」なら、設定の対象キーワードを見直してください

Q. 投稿したはずのポストが一覧に出てこない

  • Xの検索は、まれに一部の投稿を表示しないことがあります。時間をおいてもう一度取得してみてください
  • 取得中にXのタブを操作したりタブを切り替えたりすると、途中で読み取りが止まることがあります
  • リプライとして投稿したもの（自分の投稿へのリプライで続けたスレッドの2件目以降を含む）は対象外です
  • それでも出てこない場合は、その投稿を1件だけ申請フォームから手動で申請してください

Q. キャラクター欄が赤くなっていて送信ボタンが押せない

キャラクター欄が空の投稿がある状態です。欄をクリックして入力してください（登録済みのキャラクターは候補から選べます）。 申請しない投稿なら、チェックを外せば送信できるようになります。

Q. フォームへの入力の途中でエラーになる

  • 設定画面の申請フォームURLが、Twitter絵画投稿/同人小説用のものか確認してください
  • フォーム側の仕様変更で自動入力が動かなくなっている可能性があります。エラーメッセージの内容とあわせて、開発者にご連絡ください

Q.「继续填写 / 重新填写」という確認画面が出た

申請フォーム側の仕様で、以前に途中まで入力した記録が残っていると表示されます。 本拡張機能は自動的に「重新填写（最初から）」を選んで進めるので、通常は気にする必要はありません。

Q. 同じ投稿を二重に申請してしまわないか心配

送信が完了した投稿は拡張機能内に記録され、次回以降の一覧では自動的に「送信済み」表示になり、選択できなくなります。

Q. Xのパスワードなどが読み取られることはない？

ありません。本拡張機能はログイン情報を扱わず、ログイン済みのXの画面に表示された自分の投稿を読み取るだけです。 読み取った内容や設定が外部に送られることもありません。詳しくは プライバシーポリシーをご覧ください。
